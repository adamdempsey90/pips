# Editor Extensions

This directory contains editor support for the `pips` language.

- `vim/`: Vim runtime files for filetype detection, comment settings, and syntax highlighting.
- `neovim/`: Neovim runtime files for filetype detection, comment settings, and syntax highlighting.
- `vscode/`: A local VS Code extension with a TextMate grammar and language configuration.

The language rules in these editor packages are based on the current scanner and examples in the repository.
