# pips VS Code Extension

This extension adds syntax highlighting and basic language configuration for `pips` source files.

## Install locally

1. Open VS Code.
2. Open the `extensions/vscode` folder as an extension project, or package it with `vsce` if you use the VS Code extension tooling.
3. Run the `Developer: Install Extension from Location...` command and select this folder.

## Features

- `*.pips` file association
- TextMate-based syntax highlighting
- Comment, bracket, and auto-closing pair configuration
